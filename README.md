# Cybersecurity Risk Assessment Project
Thenuki Munasinghe

## Emerald Financial Solutions Ltd

This is a cybersecurity risk assessment project I created for a fictional financial services company based in Dublin.

The aim of the project was to look at the company's IT environment, identify important assets and cybersecurity threats, assess the risks and suggest ways the company could improve its security.

---

## About the Project

For this project, I worked through the different stages of a cybersecurity risk assessment.

I:

- Created a company overview
- Created an asset register
- Created a network diagram
- Identified cybersecurity threats
- Created a risk assessment
- Created a risk matrix
- Carried out a gap analysis
- Made security recommendations
- Created security policies
- Created an implementation roadmap
- Created an Excel dashboard
- Created a final report

---

## Company

**Company:** Emerald Financial Solutions Ltd  
**Industry:** Financial Services  
**Location:** Dublin, Ireland  
**Employees:** 45  
**Customers:** Approximately 2,500  
**Founded:** 2018  
**Working Model:** Hybrid

The company handles information such as customer details, bank account details, mortgage documents, payroll information and HR records.

## Main Risks Identified

I identified 10 main threats and assessed each one using likelihood and impact.

| Threat | Score | Risk Level |
|---|---:|---|
| Phishing Attack | 25 | Critical |
| Weak Passwords | 20 | Critical |
| Ransomware | 15 | High |
| Business Email Compromise | 15 | High |
| Unauthorised Network Access | 15 | High |
| Malware Infection | 12 | High |
| Laptop Theft | 12 | High |
| Unauthorised Physical Access | 12 | High |
| VPN Account Compromise | 12 | High |
| Insider Threat | 10 | Medium |

The two highest risks were **Phishing Attack** and **Weak Passwords**.

---

## Assets

Some of the main assets identified were:

- Employee laptops
- Desktop PCs
- Network switches
- Firewall
- Server
- NAS backup
- Wi-Fi access points
- Printers
- Company phones
- CCTV cameras
- Backup drives

The firewall, network switches, server and NAS backup were classified as critical assets.

---

## Security Improvements

Based on the risks identified, I recommended improvements such as:

- Multi-factor authentication
- Stronger password requirements
- Cybersecurity awareness training
- Better email security
- Endpoint protection
- Ransomware protection
- Improved backups
- Stronger network security
- Better VPN security
- Physical access controls
- Visitor management
- Clean desk practices
- Remote working security

---

## Security Policies

I created the following policies:

- Password Policy
- Remote Working Policy
- Email Security Policy
- Incident Reporting Policy
- USB Device Policy
- Bring Your Own Device (BYOD) Policy

---

## Implementation Roadmap

I created an implementation roadmap to show how the recommended improvements could be introduced.

### Phase 1
Focus on the Critical risks, including phishing, passwords, MFA and email security.

### Phase 2
Focus on High risks such as ransomware, malware, network security, VPN security and backups.

### Phase 3
Focus on physical security and security policies.

### Phase 4
Focus on monitoring, KPIs, regular reviews and continuous improvement.
